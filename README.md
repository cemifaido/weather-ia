# weather-ia
A brutalist, dot-matrix telemetry HUD for space/local weather and real-time LLM token quotas (Gemini, Claude, OpenAI).
# Weather IA

Applicazione per il recupero di dati meteorologici e l'analisi predittiva assistita da intelligenza artificiale.

## Caratteristiche
- Recupero dati meteo tramite API
- Elaborazione e sintesi delle previsioni con LLM
- Raccomandazioni pratiche personalizzate
